# COVID Resource Forecasting

Time-series forecasting to predict PPE and oxygen demand across regions.

## Tech Stack
- Python
- Pandas
- Plotly
- Prophet

## Features
- Load case/hospitalization data
- Forecast demand surges
- Dashboard for real-time planning

## Dataset
- COVID-19 case data (Johns Hopkins)
- Hospital resource data (HHS, mock data)

## Output
- Line plots of demand predictions
- Dashboards for hospitals/logistics teams
